# HTML Development

## 1. Comments

### Rule
You must add a HTML comment immediately above every logical block or section to describe its purpose and functionality.

```html
  <!-- Header navigation with logo and main menu -->
  <header>
    <nav>
      ...
    </nav>
  </header>
```
